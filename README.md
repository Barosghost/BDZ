# Beta Deutsch Zentrum

Site vitrine statique pour Beta Deutsch Zentrum (BDZ), centre de formation en langue allemande à Douala.

## Structure

- `index.html` : page principale du site
- `Beta-Deutsch-Zentrum-site (2).html` : version de travail d'origine

## Publication sur GitHub

1. Créez un dépôt GitHub public ou privé.
2. Poussez ce dossier vers la branche `main`.
3. Activez GitHub Pages dans les paramètres du dépôt.
4. Sélectionnez la branche `main` et le dossier racine (`/`).

## Démarrage local

Ouvrez simplement `index.html` dans votre navigateur, ou lancez un petit serveur local si vous préférez.
